# السجل الرقمي — DIGITAL RECORD

تطبيق iPhone وAndroid لحفظ فواتير المشتريات والضمانات والصيانة والمركبات والاشتراكات والمستندات، مع تنبيهات محلية ومساعد ذكي يجيب من سجلاتك فقط.

**التقنية:** React Native + Expo (Managed Workflow، SDK 57) + Expo Router + TypeScript + i18next.

---

## ما الموجود في المشروع

| الشاشة | الملف |
|---|---|
| الترحيب (كحلية) | `app/welcome.tsx` |
| الرئيسية (بحث، إجمالي السجلات، 4 مؤشرات، الخط الزمني، المساعد، أحدث السجلات) | `app/(tabs)/index.tsx` |
| سجلاتي (بحث + مرشحات + ترتيب الأقرب انتهاءً) | `app/(tabs)/records.tsx` |
| إضافة سجل جديد (8 أنواع) | `app/(tabs)/add.tsx` |
| نموذج الإضافة / التعديل (تصوير الفاتورة) | `app/record/new.tsx` |
| تفاصيل السجل (الضمان / الفاتورة / البيانات) | `app/record/[id].tsx` |
| التنبيهات | `app/(tabs)/alerts.tsx` |
| المزيد: شبكة الخدمات 3×3 + الإعدادات | `app/(tabs)/more.tsx` |
| المساعد الذكي | `app/assistant.tsx` |

### إضافات مبتكرة فوق التصميم
- **حقيبة المطالبة:** زر واحد يجهّز ملخص الضمان (المنتج، المتجر، رقم الفاتورة، التواريخ، المتبقي) ويرسله للمتجر عبر واتساب أو البريد، مع صورة الفاتورة.
- **قيمة مشترياتك المحمية:** مجموع أسعار ما زال تحت الضمان، يظهر في الرئيسية.
- **الخط الزمني الذكي:** بطاقات أفقية لكل ما ينتهي خلال 30 يومًا (ضمان، إرجاع، تجديد).
- **مهلة الإرجاع:** متابعة أيام الإرجاع مع تذكير قبلها بـ 3 أيام ويوم.
- **«تم — جدولة الموعد التالي»:** للصيانة والاشتراكات المتكررة، ينقل الموعد تلقائيًا ويسجّل ملاحظة.
- **المساعد الذكي يعمل بلا إنترنت وبالسبع لغات**، ولا يرسل أي بيانات خارج الجهاز.
- **إدخال التاريخ بأي لوحة مفاتيح:** يقبل الأرقام العربية ٢٠٢٥/٤/٢٢ ويحوّلها تلقائيًا.
- **عملة افتراضية حسب بلد الجهاز** (SAR، AED، USD، EUR…).
- **نسخ احتياطي واستعادة** بملف JSON، والمفضلة، وصورة الفاتورة بملء الشاشة.

### اللغات
العربية (RTL كامل)، الإنجليزية، الفرنسية، الإسبانية، الألمانية، البرتغالية، التركية. يختار التطبيق لغة الجهاز تلقائيًا، ويمكن تغييرها من «المزيد ← اللغة». الترجمات في `src/i18n/locales/` وكل ملف مُلزَم بنفس مفاتيح الإنجليزية (TypeScript يرفض أي مفتاح ناقص). لإضافة لغة: انسخ `en.ts`، ترجمه، وأضفه في `src/i18n/index.ts`.

اسم التطبيق تحت الأيقونة وأذونات الكاميرا مترجمة أيضًا في `locales/*.json`.

## البناء السحابي والنشر (EAS)
1. أنشئ حسابًا على **expo.dev** ثم مشروعًا باسم `digital-record`، وانسخ **Project ID**.
2. من expo.dev ← Access tokens أنشئ رمزًا.
3. في GitHub ← Settings ← Secrets and variables ← Actions أضف Secret باسم `EXPO_TOKEN`.
   - المعرّفان `com.kh11kk.digitalrecord` ومعرّف مشروع EAS محفوظة في `app.json`. متغيرات `IOS_BUNDLE_ID` و`ANDROID_PACKAGE` و`EAS_PROJECT_ID` لا تغيّرها. `EXPO_OWNER` وحده اختياري لتحديد الحساب عند تشغيل الإعداد.
4. **بيانات التوقيع (مرة واحدة):** أول بناء يحتاج شهادات Apple ومفتاح Android. أسهل طريقة: تشغيل `eas build` مرة واحدة من أي كمبيوتر بشكل تفاعلي (يسجّل دخول Apple وينشئ كل شيء ويحفظه على expo.dev). بعدها تعمل كل البناءات من GitHub تلقائيًا.
5. سير العمل **Build iOS and Android pilot** يبني المنصتين، يفحص الكود أولًا وينتظر اكتمال البناء ويحتفظ بنتيجته. يبدأ عند تغيير ملف سيره في فرع التجربة، أو يدويًا إذا كان الملف موجودًا على الفرع الافتراضي. يمكن إعادة محاولة التشغيل من Actions.
   - `production` ← ملف **AAB** لـ Google Play و**IPA** لـ App Store.
   - `preview` ← ملف APK للتجربة المباشرة على أندرويد.
   - البناء لا يعني الرفع. إرسال Apple يحتاج `ascAppId` ومفتاح App Store Connect مرتبطًا بالتطبيق في Expo. إرسال Android يحتاج مفتاح Google Service Account مرتبطًا بالتطبيق في Expo وصلاحية رفع إصدارات الاختبار. يمكن رفع أول إصدار عبر EAS Submit بعد إتمام متطلبات Google Play الحالية؛ راجع https://docs.expo.dev/submit/android/.

ملفات الإعداد: `eas.json` للبناء والإرسال و`app.json` للإعدادات الثابتة. `app.config.ts` يقرأها ويضيف اسم مالك Expo عند ضبطه.

## الخصوصية
السجلات والصور والتنبيهات تُحفظ محليًا (AsyncStorage + مجلد التطبيق الخاص). الإدخال اليدوي والمساعد المحلي لا يحتاجان خادمًا. عند تفعيل قراءة الفواتير الاختيارية والضغط على «قراءة»، تُرسل الصورة إلى خادم القراءة وGoogle؛ راجع مسودة الخصوصية في `docs/privacy-policy.md` قبل التفعيل.

## ما الذي تغيّر عن مشروع Manus ولماذا
مشروع Manus كان مبنيًا على خوادم Manus (تسجيل الدخول OAuth، قاعدة MySQL، قراءة الفواتير بالذكاء الاصطناعي، تخزين S3) ولا يعمل خارج بيئتهم. أُعيد بناؤه مستقلًا تمامًا مع الحفاظ على منطقه:
- نُقل منطق الضمان (إضافة الأشهر مع ضبط نهاية الشهر)، مهلة الإرجاع، المواعيد المتكررة، جدولة التذكيرات (90/30/7/1، و3/1 للإرجاع، بحد 48 تذكيرًا)، وانتقاء مصادر المساعد بالسبع لغات.
- أُصلح: معرّف التطبيق `space.manus…` ورابط `manus…` (لا يُقبلان للنشر باسمك)، غياب `eas.json`، أيقونة «باقي» القديمة (استُبدلت بهوية السجل الرقمي)، ملفات قالب غير مستخدمة (react-logo)، وخيار `baseUrl` المهجور في TypeScript 6.
- مُطابق لتصاميم الصورة: الألوان الكحلية `#102B4E` والزرقاء `#2463EB`، البطاقات البيضاء، شريط التنقل مع زر (+) في الوسط.
